# TGSC project continuity

Before starting or resuming TGSC work, including after context compaction or in a new session, read `docs/TGSC_IMPLEMENTATION_PROGRESS.md` first. Use it to recover accepted decisions, current task status, verification history, and the next action. Then consult `TGSC_IMPLEMENTATION_TASKS.md` and `TGSC_INTEGRATION_PLAN.md` as directed.

Check the live working tree before continuing; the progress report is context, not proof that files or checks remain unchanged. Follow the latest user instructions if they supersede recorded decisions.

Keep the progress report current after meaningful task progress, decisions, checks, or interruptions, and before ending an implementation turn. Record partial work and the concrete next action so work can resume after compaction.
